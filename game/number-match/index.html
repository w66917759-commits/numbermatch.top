About This Game

Number Match is a local browser puzzle based on the classic take-ten number game. Clear the board by pairing equal numbers or two numbers that add up to 10. This build starts with a playable LV0 tutorial that teaches each rule with live prompts, then moves into two gated difficulty levels: a shuffled 8x8 first board and a much larger 20x20 second board that only unlocks after Level 1 is cleared.

How to Play

  • Start with LV0 to play through examples for equal numbers, numbers adding to 10, and one-turn connections.
  • Select two equal numbers or two numbers that add up to 10.
  • Pairs can clear horizontally, vertically, diagonally, across the end of one row into the next, or with one empty right-angle turn when the path is open.
  • Level 1 and Level 2 each allow three hints per run, and every successful pair draws a connection before disappearing.

Tips

  • Open with the few visible adjacent pairs, then use the empty spaces to reveal longer paths.
  • On the 20x20 board, work row by row so the large grid stays readable.
  • If no pairs remain, restart and try a different clearing order.

FAQ

Do I need to install anything to play Number Match?

No, the game is a local browser-based HTML5 build - just open the page and start playing.

Does this version use an iframe?

No. The puzzle board, level lock, matching rules, and scoring all run from local code.
